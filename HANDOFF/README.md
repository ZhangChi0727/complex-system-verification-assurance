# Handoff Workspace

本目录记录仓库当前开发进度与下一步计划，服务于任何接手者（人或 agent）快速建立现状认知。

**更新纪律：** 每次合并 PR 或基线变更后更新本目录。CHANGELOG 记录"改了什么"（历史流水），HANDOFF 记录"现在在哪、下一步去哪"（现状快照）。HANDOFF 不是事实源——规范性内容仍以 `docs/` 各文件为准，本目录只做状态汇总与指针。
