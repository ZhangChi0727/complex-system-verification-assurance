# Verification Terminology Baseline

> 本文件为工作基线。正式定义必须补充来源、版本、条款和必要的语境说明。

| Term | Working meaning | Boundary / note |
|---|---|---|
| Verification | 形成客观证据以确认规定要求已得到满足的活动集合 | 不等同于 test；具体定义按标准语境记录 |
| Validation | 确认需求、系统或产品对预期用途/运行语境是否适当 | 与 design implementation verification 分离 |
| Verification Objective | 需要通过验证活动达成的目标 | 五列映射的第二列 |
| Verification Obligation | 针对某项要求，需要被证明的内容 | 由 requirement 产生 |
| Verification Strategy | 对 level、method、technique、environment、configuration、oracle、coverage 与 evidence 的受控选择 | Case 设计的输入 |
| Information Item | 活动使用、更新或产生的受控信息对象 | 不预设必须是独立文档 |
| Evidence | 支撑 claim 的受控、可追溯、可复核信息 | 必须带配置与来源语境 |
| Compliance Claim | 对符合性或目标满足情况作出的可审查陈述 | Traceability 本身不构成 argument |
| Project Practice | 由组织或当前 DCAS 项目采用、尚无规范性来源证明的做法 | 不得标记为国际或航空规则 |
