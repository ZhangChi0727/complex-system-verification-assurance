# ISO/IEC/IEEE 15288:2023 Reading Notes

## Public metadata confirmed

- Title: *Systems and software engineering — System life cycle processes*
- Edition 2; publication date 2023-05; status Published.
- Public scope establishes a common framework of system life-cycle process descriptions and states that it does not prescribe a specific life-cycle model, development methodology, modelling approach, or technique.

## Clause-level review queue

- Verification Process purpose, outcomes and activities;
- Validation Process boundary;
- Technical processes that provide verification inputs or consume outputs;
- Configuration Management, Information Management, Decision Management and Risk Management relationships;
- required records versus project-defined information item forms.
