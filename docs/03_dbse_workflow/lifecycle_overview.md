# DBSE Verification Lifecycle V0.1

```text
V0 Planning → V1 Basis → V2 Verifiability → V3 Strategy → V4 Case Design
→ V5 Procedure → V6 Readiness → V7 Execution → V8 Evaluation
→ V9 Anomaly → V10 Regression → V11 Coverage & Sufficiency → V12 Closure
```

| ID | Activity | Primary output | Baseline state |
|---|---|---|---|
| V0 | Verification Planning | Verification Plan | candidate |
| V1 | Verification Basis Establishment | Verification Basis Baseline | candidate |
| V2 | Requirement Verifiability Analysis | Verification-ready Requirement | candidate |
| V3 | Verification Strategy Definition | Verification Strategy Record | candidate |
| V4 | Verification Case Design | Verification Case | candidate |
| V5 | Verification Procedure Development | Verification Procedure | candidate |
| V6 | Verification Readiness | Readiness Review Record | candidate |
| V7 | Verification Execution | Execution Record / Raw Evidence | candidate |
| V8 | Result Evaluation | Verification Result | candidate |
| V9 | Anomaly Management | Anomaly / Disposition | candidate |
| V10 | Regression | Regression Scope and Result | candidate |
| V11 | Coverage & Sufficiency | Coverage/Sufficiency Assessment | candidate |
| V12 | Verification Closure | Accomplishment / Closure Report | candidate |

每项活动后续统一定义 purpose、normative basis、inputs、entry criteria、roles、process、decision rules、outputs、records、traceability、independence、configuration 和 exit criteria。
