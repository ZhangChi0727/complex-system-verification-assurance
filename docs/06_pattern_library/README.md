# Verification Pattern Library Workspace

初始 working proposal：

- `BVA-01` Boundary Value Verification
- `EQP-01` Equivalence Partition Verification
- `LOG-01` Boolean Logic Verification
- `STM-01` State Transition Verification
- `SRC-01` Source Selection Verification
- `TIM-01` Timing Verification
- `ROB-01` Robustness Verification
- `FIT-01` Fault Injection Verification
- `RED-01` Redundancy / Reconfiguration Verification
- `INT-01` Integrity Verification
- `IFV-01` Interface Verification
- `CFG-01` Configuration-Dependent Verification

名称、taxonomy、coverage obligations 与 applicability limits 均未冻结。
