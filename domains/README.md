# Domain Profiles

Domain Profile 使用特定领域的 architecture、interfaces、constraints、patterns、examples 和 tooling 实例化 Generic Verification Framework。

领域实例可以暴露通用框架的 gap，但不能把领域或组织惯例直接提升为 generic rule。任何向 `docs/` 的反馈都必须给出跨领域理由和 normative basis 或明确 research rationale。

当前 domain workspace：`dcas/` 定位为 industrial-practice knowledge source（非框架验证实例）；框架验证实例统一管理于 `docs/08_validation/`。
