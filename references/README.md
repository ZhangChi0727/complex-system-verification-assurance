# References

**Purpose:** 保存合法 bibliographic metadata、检索策略、阅读记录、条款定位和自行撰写的 interpretation。

## Policy

- 不提交 SAE、RTCA、未授权 EUROCAE/ISO 等标准全文或未经授权的复制件；
- 不提交 proprietary DCAS 文档、内部 URL、credentials、IP 地址或 confidential interfaces；
- 不可公开资料只记录 `Source available internally — not committed`；
- 未完成 clause-level review 的解释标记为 `working`、`TBD` 或 `interpretation`；
- `bibliography.bib` 不得编造 DOI、作者、版本或出版信息。

**Status:** Working；依赖合法资料可得性。
